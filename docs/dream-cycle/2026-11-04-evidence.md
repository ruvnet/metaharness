## INFERENCE
- The gap is best explained as a structural consequence of ADR-045's
  deliberate "dependency-free mirror" design (host-config.ts cannot import
  `@metaharness/host-prime-agent` to keep the published CLI standalone):
  a fail-closed security control added to the canonical adapter has no
  compiler- or test-enforced guarantee of propagating to either mirror
  unless a human (or a future Dream Cycle night) notices and ports it by
  hand. This is the same class of risk the Deep Researcher's runner-up
  candidate (CLI/web-UI MCP command divergence) independently surfaced on
  the *other* mirror pairing tonight — corroborating, not duplicating.
- Zero downstream blast radius (no in-repo importer of either touched
  file outside its own package/tests, confirmed via repo-wide grep) is an
  inference about today's import graph, not a guarantee about future
  consumers.
