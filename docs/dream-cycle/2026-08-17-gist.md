# darwin-evolution SOTA Report — 2026-08-17

**TL;DR**: ADR-249 (2026-08-10) shipped an opt-in `signals.cost` seam on Darwin's frozen scorer so a
caller could feed a deterministic cost figure instead of leaving `costEfficiency` pinned at 1.0 — but
nothing in production `evolve()` ever called it. Tested in isolation, then left unreachable. Tonight
wires it: `EvolutionConfig` gains optional `costBudgetBytes`; when set, `evaluateVariant` feeds the
*already-computed* `variantBytes(variant.dir)` signal (previously only a Pareto tie-break) through the
seam. Omitted, the path is untouched — byte-identical. Closes a "decision shipped, implementation
dangling" gap found by reading ADR-249 against the actual call graph, not by guessing.

## Hypothesis

Given `evaluateVariant`, which already computes `variantBytes(variant.dir)` (deterministic surface
size) elsewhere for Pareto tie-breaking but feeds no signal into `scoreVariant`'s ADR-249
`signals.cost` seam, when `EvolutionConfig` gains an optional `costBudgetBytes` and, only when it's
set, `evaluateVariant` passes `{ cost: { units: variantBytes(variant.dir), budgetUnits: costBudgetBytes } }`
into `scoreVariant`, then a variant whose surface grows past budget should score strictly lower
`costEfficiency` (and, on a crafted near-tie fixture, flip a promotion from promoted to not), while
every existing caller — none set `costBudgetBytes` — stays byte-identical, subject to: (a) zero
regression in the 632-test suite, (b) omitted-field behavior byte-identical, (c) `scorer.ts` untouched,
(d) diff materially under 300 lines.

0.385 (not) — no other gate clause moves.

**Reward-hack angle checked, not new**: `variantBytes` is the *same* signal already used for Pareto
tie-breaking before this diff — if it were gameable by whitespace-stripping mutations, that property
predates tonight. This diff does make it more consequential (now inside the score, not just a
tie-break) — disclosed below, not hidden.

**Also checked tonight (static, $0)**: darwin-mode's SWE-bench solvers (`bench/swebench/*.mjs`) all

## Adversarial Critique

Independent critic (no authorship context) reviewed the diff — verdict **ACCEPT**. Independently
re-ran `evolve.test.ts` (9/9), `tsc --noEmit`, and the full suite (632/14 — matched). Traced the
omitted-field path directly (not trusting comments): `signals` is literally `undefined` when
`costBudgetBytes` is unset. Re-derived the promotion-flip arithmetic independently and confirmed both
outcomes. Confirmed every variant directory is fully written (all writes `await`ed) before
`evaluateVariant` reads it — no read-before-write race. Two **disclosed, non-blocking** caveats: (1)
`variantBytes`'s pre-existing gameability (whitespace-stripping) is now score-consequential, not just
tie-break-consequential, once a caller opts in (none does yet); (2) `copyVariantDir` (pre-existing,
unrelated) merges rather than clears on reuse, so a `workRoot` shared across runs with colliding
variant ids could inflate a byte count with stale files — an existing sharp edge, not a new one.
