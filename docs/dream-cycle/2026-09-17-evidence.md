## INFERENCE

- The dry-run/`--run` asymmetry was a genuine, disclosed-but-unaddressed trust gap: the
  entire point of a $0 dry-run in a command whose real mode can cost real API spend is to
  let an operator sanity-check the invocation first. A dry-run that accepts an invalid input
  and reports success gives false confidence exactly where confidence matters most.
- The ADR-235/ADR-228 mix-up is a plain citation defect (verified by reading both ADRs in
  full: ADR-235 is entirely about flywheel replay verifiers, no §9, no mention of `learn` or
  gateway jobs anywhere in it; ADR-228 is the actual GEPA/executor-genome ADR, and its own
  §9 is literally titled "Implementation — `bench/swebench/gepa/`" — the section the wrong
  citations claimed was in ADR-235). Bundling this fix with the validation fix was
  reasonable (same files, same command surface, zero logic risk) rather than opening a
  second PR for a pure string correction.

  but it has now been raised on 2026-09-15 (#313) and 2026-09-16 (#319) without a merge
