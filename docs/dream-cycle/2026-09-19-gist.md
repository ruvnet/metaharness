# Host-Adapters SOTA Report — 2026-09-19

TL;DR: `HarnessSpec.autonomous` (ADR-246 §2.2) carries an explicit contract —
"host adapters must project this block per host or emit an explicit
documented no-op — never silently drop" — that 9 of 10 host adapters
violated outright: `goal`/`heartbeat`/`gateCommand`/`maxTurns` vanished with
zero trace in every generated file. Fixed all 9 with either a real
projection (where the host has a native equivalent) or an explicit,
tested no-op disclosure. An independent critic caught that one host
(GitHub Actions) deserved real projection, not just disclosure, of
`heartbeat.cadence`/`gateCommand` onto its native `schedule:`/gating
surface — closed same night in a round-2 patch.

## Hypothesis

Given a `HarnessSpec` with a non-empty `autonomous` block, when each of the
9 non-compliant host adapters' render entrypoint runs, then the generated
output must contain either (a) a real projection onto that host's native
equivalent surface, or (b) an explicit, tested disclosure that the block is
not projected — never silent omission — subject to: 0 regressions in each
package's existing suite; no adapter interpolates an unescaped harness-spec
field into the new content (no ADR-046-class reintroduction); GitHub
Actions specifically must use its real `schedule:`/gating surface for
`heartbeat.cadence`/`gateCommand` rather than disclosure alone, per the
independent critic's round-1 finding.

  ACCEPT-WITH-CAVEATS — confirmed clean reward-hack check, confirmed all 9

  `schedule:`/gate projection (its own file already had a commented-out
  cron example) rather than a bare no-op.
- **Round 2** (same night): `workflowYaml()` now projects a cron-shaped
  `heartbeat.cadence` onto a real `schedule:` trigger (falls back to

  and `gateCommand` onto a real pre-flight gating step (job fails if it
  exits non-zero), both via the same `JSON.stringify` safe-scalar pattern
  already used for `spec.name` elsewhere in this file. Re-ran red proof for
  GitHub Actions alone: 7/33 new assertions fail non-vacuously pre-fix,
  26/33 baseline unaffected.
- **Final**: all 9 packages green — 192/192 tests (claude-code 16,
