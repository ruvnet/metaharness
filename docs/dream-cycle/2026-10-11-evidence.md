## OBSERVATION

- `packages/flywheel/src/review-context.ts` (ADR-317, status Proposed) builds `IndependentReviewPacket`s
  for independent reviewers. `digestPacket()` (line ~261, pre-fix) is `sha256(canon(unsignedPacket))` — an
  **unkeyed** digest with no secret/key input anywhere in `prepareIndependentReviewPacket`/
  `verifyIndependentReviewPacket`. ADR-317's own "Trust boundary" section discloses this outright:
  "`packetDigest` is an unkeyed SHA-256... it does not authenticate who prepared the packet. Anyone can
  mint a packet that verifies."
- Confirmed via `grep -rln "review-context\|IndependentReviewPacket" packages apps` (excluding
  `__tests__`/`.d.ts`): the module has **zero production callers** — only `review-context.ts` itself and
  `index.ts`'s re-export reference it. Zero migration risk for any additive change.

## INFERENCE

- This is a trust-boundary HARDENING, not a bug fix in the conventional sense: ADR-317 explicitly
  discloses the unkeyed-digest property as an accepted "Negative" consequence, not an oversight. Tonight's
  honesty-ladder-correct framing (ADR-250) is therefore "adds an opt-in stronger guarantee for callers that
  want producer authenticity" — not "fixes a bug ADR-317 missed." Overclaiming the latter would be a
  defect under this repo's own SOTA-proof-ladder discipline.
- The actually-bigger gap ADR-317 names — "no runner consumes it yet" (zero production integration) — is
  NOT closed tonight and is not claimed to be. Building the real reviewer-job launcher that materializes
  only referenced evidence and denies shared-memory/peer surfaces is a product-level decision (which role
  dispatches it, where review happens) too large for one conceptual change; flagged as next steps #1 in
  the gist, not attempted here.
- Binding `evidence[].sourceDigest` to the package's own signed receipts/replay bundles (rather than
  self-reported) is a distinct, real follow-up gap the Deep Researcher surfaced: even a signed packet
  today does not prove its cited evidence traces back to anything real. Correctly scoped as a SEPARATE
  future candidate (M-sized, ~100-150 LOC) rather than folded into tonight's diff.
