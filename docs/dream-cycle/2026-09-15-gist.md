# Agent-Topology Recommendations Trusted a Manifest, Not Reality — 2026

TL;DR: `harness genome`'s exported `agent_topology` field recommended the
`'tester'` maintenance-agent role for any rust or python repo purely because
a language was detected — even one with zero real test files and no CI.
The sibling scorer `scoreTestConfidence` was fixed for this exact
manifest-vs-reality gap on 2026-08-25 (#229); `resolveAgentTopology` was
never updated in lockstep. Fixed with a 1-line gate + 2 new tests. Three
more untouched siblings of the same pattern, and a separate structurally-
unreachable branch in `scoreMcpRisk`, are disclosed for future nights
rather than folded into tonight's diff — deliberately, given the current
review backlog (6 Dream Cycle PRs open, 0 merged, since 2026-09-05; see
issue for detail).

## MetaHarness Current Capability

`harness genome <repo>` (packages/create-agent-harness/src/genome.ts) emits
a 6-field scorecard including `agent_topology: string[]`, computed by
`resolveAgentTopology(profile, plan)`. `profile.testCommands` is populated
in `analyze-repo.ts` from language detection alone — `languages.includes
('rust')` unconditionally pushes `'cargo test'`, `languages.includes
('python')` unconditionally pushes `'pytest'` — independent of
`profile.hasVerifiedTestFiles` (a real `tests/`/`__tests__/`/`test`
directory scan). `resolveAgentTopology`'s `'tester'` gate read
`testCommands.length > 0 || hasCi`, so it could not tell "this repo has
real tests" from "this repo is written in Rust."

## Hypothesis

Given a repo profile where `testCommands` is populated purely by language
detection (rust and/or python) with `hasVerifiedTestFiles: false` and
`hasCi: false`, when `resolveAgentTopology` computes the recommended agent
topology, then `'tester'` should NOT be included — where before it always
was — subject to: (a) `hasVerifiedTestFiles: true` or `hasCi: true` still
includes `'tester'`, unchanged; (b) 0 regressions in the other 4
`genome-scorers.ts` exports; (c) the new test fails non-vacuously
pre-patch. Frozen before implementation, not modified after.
