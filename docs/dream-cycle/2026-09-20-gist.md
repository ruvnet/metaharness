# generator-genome SOTA Report — 2026-09-20

TL;DR: `harness score`'s composite grade can read "Grade A, release-ready" while its own MCP-safety dimension is flagging `mcpRisk: 'High'` (unrestricted shell execution granted to MCP tools) — because MCP safety is only 20% of the weighted average. ## MetaHarness Current Capability

No competitor combines publish-readiness + test-confidence + repo-understanding + tool/MCP-safety into one static score-diag-doctor pass — that composition is genuinely underexplored, likely because most frameworks emit one canonical scaffold shape from their own CLI, leaving little combinatorial variation to score. **Verdict: MetaHarness's static composite-scoring niche remains differentiated in 2026, but the MCP-safety slice specifically faces real, commercially-backed convergence — making tonight's fix (closing a real hole in exactly that slice) directly relevant competitively, not just internally.**

## Hypothesis
Given a generated harness whose `scoreMcpSafety` dimension classifies `mcpRisk` as `'High'`, when `buildScorecard` computes the overall grade, then the final grade must be capped at `'C'` (exitCode ≥ 1), never `'A'`/`'B'`, regardless of the weighted composite from the other 4 dimensions — subject to: `mcpRisk` of `'None'`/`'Low'`/`'Medium'` scored exactly as before; per-dimension scores/signals unchanged; 0 regressions.
