# Security-Adversarial SOTA Report — 2026-10-08

TL;DR: `main`'s own `.github/workflows/security.yml` has been failing
(`npm-audit` + `audit-deps-aggregate`, conclusion=`failure`) on every push
for at least several days — confirmed via the Actions API on the latest 5
runs, not inferred. Cause: 3 production (non-dev) dependency advisories —
`@grpc/grpc-js` (high, GHSA-m9gg-hp2v-232j), `@modelcontextprotocol/sdk`
(high, GHSA-6qxp-vccf-f47h, an MCP OAuth confused-deputy bug), `proxy-addr`
(critical, GHSA-jqcg-44mw-7w3h, IP-spoofing) — reachable through
`packages/agntcy` and `packages/arc-agi-3-chatgpt`. The CI gate this repo
built for exactly this purpose has been red and unactioned, separate from
(but likely entangled with) the known PR review backlog. Root cause of
why `npm audit fix` alone couldn't close it: the SDK was **exact-pinned**
(`"1.26.0"`, no caret), blocking npm's automatic non-major remediation.
Fixed: widened to `^1.32.1` (non-major, per `npm audit fix`'s own
`fixAvailable` metadata) and let `@grpc/grpc-js`/`proxy-addr` resolve
within their already-permissive parent ranges. `npm audit --omit=dev
--audit-level=high` now passes; `harness audit` agrees. 2 new regression
tests assert the resolved versions stay at/above each GHSA's patched floor.

## Hypothesis
Given `main`'s existing `.github/workflows/security.yml` `npm-audit` +
`audit-deps-aggregate` gate (already fail-on-high+, already wired, already
running on every push), when `@modelcontextprotocol/sdk`'s exact pin in
`packages/arc-agi-3-chatgpt/package.json` is widened to a caret range at
the already-available non-major patched version, and `@grpc/grpc-js` /
`proxy-addr` are allowed to resolve within their existing parent ranges,
then `npm audit --omit=dev --audit-level=high` should report 0 advisories
and both previously-failing CI jobs should pass on this commit — subject
to: zero behavioral change to any passing test, zero new direct
dependency, zero other importer of the touched packages regressed, and a
regression test that fails pre-fix/passes post-fix for each of the two
directly-reachable advisories.
