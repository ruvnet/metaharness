## OBSERVATION
`packages/create-agent-harness/src/repo-scorecard.ts`'s `buildRepoScorecard()` computes
`compileConfidence` and `taskCoverage` using `profile.testCommands.length > 0` as a boolean
test-evidence signal. `packages/create-agent-harness/src/analyze-repo.ts`'s `analyzeFiles()`
populates `testCommands` unconditionally from manifest/language detection: any repo with a
`pyproject.toml` or `requirements.txt` gets `'pytest'` pushed, any `Cargo.toml` gets
`'cargo test'`, any `go.mod` gets `'go test ./...'` — none of these require a single real
test file to exist on disk.

## MEASUREMENT
Constructed two fixtures differing ONLY in the presence of a `tests/` directory with one
real test file:
- `manifestOnly`: `pyproject.toml` only, no `tests/` dir.
- `withRealTests`: same `pyproject.toml`, plus `tests/test_x.py` with one real assertion.

## INFERENCE
The bug is real, not a vacuous or confound-prone repro: the two fixtures are byte-identical
except for the presence of a real test file, and both scoring dimensions' pre-fix values are
mathematically forced to collide whenever `testCommands.length > 0` is the only test-evidence
signal consulted, because `testCommands` is set by manifest detection alone regardless of real
test files. This is the 5th instance (across `resolveAgentTopology` #314 merged,
`scoreTestConfidence` #229 merged, `scorePublishReadiness` #451 open, `score.ts`'s
`scoreTestCoverage` #435 open, and now this) of the identical "manifest implies tests" bug
class in this package — the pattern is well-established enough that the fix shape
(`hasVerifiedTestFiles || testCommands.includes('npm test')`) is not novel engineering, just
consistent application of an already-proven carve-out to a 5th sibling scorer.

## HYPOTHESIS (frozen before implementation — see gist for full statement)
Gating `compileConfidence`/`taskCoverage`'s test-credit term on real evidence
(`hasVerifiedTestFiles || testCommands.includes('npm test')`) makes a manifest-only repo score
strictly lower than an identical repo with real test files, while leaving the real-evidence
repo's score, and all 18 pre-existing assertions, unchanged.
