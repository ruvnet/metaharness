## DECISION

- **Fix applied**: removed the `if (plan.policy.defaultDeny) s += 0.05` line
  from `scorePublishReadiness`; `plan` stays in the signature for
  call-site/API stability with sibling scorers in the same file, though now
  unused in this function.
- **Correction** (critic-caught, disclosed rather than silently fixed in
  the commentary): the commit message states defaultDeny is hardcoded at
  "analyze-repo.ts, index.ts" — `index.ts:642`'s `defaultMcpPolicy()` is
  actually an unrelated, untyped scaffold-output object (`.mcp/servers.json`
  for a *generated* harness), not a `HarnessPlan` constructor. The real and
  only mechanism is `recommendPlan()`'s hardcoded `SAFE` constant. The
  underlying claim (defaultDeny is always `true` for genome scoring) is
  unaffected; only the "which second file" detail was wrong, corrected here
  per ADR-250 (a claim must not outlive its evidence).
- **Disclosed-not-fixed, not actioned tonight** (kept this diff to one
  conceptual change, per critic's finding):
  - `scoreMcpRisk` (`genome-scorers.ts:86`): `const permissive = p.allowShell
    || p.allowNetwork || p.allowFileWrite || !p.defaultDeny;` — the
    `!p.defaultDeny` disjunct is the *same* dead-constant family (always
    `false` given `defaultDeny` is always `true`), currently harmless only
    because it sits inside an OR with three other, real flags. Good
    candidate for a near-future generator-genome night.
  - `router-calibration-loop`'s outcome-anchoring gap (standing, disclosed
    2026-11-10 and reconfirmed tonight's router scan): the economics claim
    is refuted 3/3 seeds because `toQualityLabels` collapses to near-base-rate
    via within-trajectory standardization.
  - `turn-credit`'s non-finite-number hardening (`receipt.ts`'s `canon()`,
    ported 2026-10-26) was never extended to `processor.ts`/`belief.ts`/
    `reshape.ts`/`cli.ts` — a NaN/Infinity-contaminated credit written via
    `--out` silently collapses to JSON `null`.
  - `vertical-packs` (ADR-013, Proposed): only `vertical-trading` has been
    externalized into its own package per the ADR's stated shape; 18 of 19
    `vertical_*` templates remain inside `create-agent-harness` itself.

    unauthenticated peer-registry CRUD; the ADR's signature-verification
